# ValutaTrade Hub

Консольная платформа для отслеживания курсов валют и симуляции торговли фиатными и криптовалютами.

## 1. Описание проекта

ValutaTrade Hub — учебное приложение, позволяющее пользователям регистрироваться, управлять валютными портфелями, моделировать покупку и продажу валют, а также отслеживать актуальные курсы обмена.

Данные пользователей, портфелей и курсов сохраняются в JSON-файлах.

## 2. Основные возможности

- Регистрация и авторизация пользователей.
- Создание и просмотр персонального валютного портфеля.
- Покупка и продажа фиатных и криптовалют.
- Проверка достаточности средств при продаже.
- Получение прямых и обратных курсов обмена.

Поддерживаемые валюты:
-  Базовая: USD.
-  Фиатные: EUR, GBP, RUB.
-  Криптовалюты: BTC, ETH, SOL.


## 3. Модель симуляции торговли

В проекте реализована упрощённая модель торговли валютами.

- Команда 'buy' увеличивает баланс кошелька покупаемой валюты на указанное количество. Списание средств с USD-кошелька не производится.
- Команда 'sell' уменьшает баланс кошелька продаваемой валюты на указанное количество. При недостаточном балансе возникает 'InsufficientFundsError'.
- Выручка от продажи и стоимость покупки отображаются в USD как оценочные значения, рассчитанные по актуальному курсу.
- USD используется исключительно как базовая валюта для расчёта и отображения стоимости портфеля.

Стартовый баланс USD, пополнение счёта и предварительное создание USD-кошелька не предусмотрены, поскольку они не требуются в рамках выбранной упрощённой модели.


## 4. Установка и запуск

## Требования

- Python 3.10 или выше.
- uv
- API-ключ ExchangeRate-API.

## Установка

Клонируйте репозиторий и перейдите в папку проекта:git clone <ссылка-на-репозиторий>
cd valutatrade_hub

Установите зависимости: 
uv sync
pip install requests

### Запуск

Запустите приложение:uv run ????

Проверка кода

Проверьте код с помощью Ruff: uv run ruff check .


## 7. Описание команд
После запуска приложения открывается интерактивный интерфейс командной строки с приглашением valutatrade>.

register --username USERNAME --password PASSWORD - Регистрация нового пользователя
login --username USERNAME --password PASSWORD - Вход в учётную запись
logout - Выход из текущей учётной записи
show-portfolio - Просмотр текущего портфеля в USD
show-portfolio --base EUR - Просмотр портфеля с оценкой в указанной базовой валюте
buy --currency BTC --amount 0.001 - Покупка указанного количества валюты
sell --currency BTC --amount 0.0005 - Продажа указанного количества валюты
get-rate --from USD --to EUR - Получение курса одной валюты к другой
help - Вывод списка доступных команд
exit - Завершение работы приложения
