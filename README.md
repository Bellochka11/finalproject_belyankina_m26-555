# ValutaTrade Hub

Консольная платформа для отслеживания курсов валют и симуляции торговли фиатными и криптовалютами.

## 1. Описание проекта

ValutaTrade Hub — учебное приложение, позволяющее пользователям регистрироваться, управлять валютными портфелями, моделировать покупку и продажу валют, а также отслеживать актуальные курсы обмена.

Приложение использует USD в качестве базовой валюты. Курсы фиатных валют получает из ExchangeRate-API, а курсы криптовалют — из CoinGecko.

Данные пользователей, портфелей и курсов сохраняются в JSON-файлах.

## 2. Основные возможности

- Регистрация и авторизация пользователей.
- Создание и просмотр персонального валютного портфеля.
- Покупка и продажа фиатных и криптовалют.
- Проверка достаточности средств при продаже.
- Получение прямых и обратных курсов обмена.
- Обновление курсов из внешних API.
- Выбор источника обновления курсов.
- Кэширование курсов с ограниченным временем действия.
- Сохранение истории изменения курсов.
- Логирование пользовательских операций.

Поддерживаемые валюты:
-  Базовая: USD.
-  Фиатные: EUR, GBP, RUB.
-  Криптовалюты: BTC, ETH, SOL.


## 3. Модель симуляции торговли

В проекте реализована упрощённая модель торговли валютами.

- Команда 'buy' увеличивает баланс кошелька покупаемой валюты на указанное количество. Списание средств с USD-кошелька не производится.
- Команда 'sell' уменьшает баланс кошелька продаваемой валюты на указанное количество. При недостаточном балансе возникает 'InsufficientFundsError'.
- Выручка от продажи и стоимость покупки отображаются в USD как оценочные значения, рассчитанные по актуальному курсу.
- USD используется исключительно как базовая валюта для расчёта и отображения стоимости портфеля.

Стартовый баланс USD, пополнение счёта и предварительное создание USD-кошелька не предусмотрены, поскольку они не требуются в рамках выбранной упрощённой модели.


### Назначение модулей

- 'cli' — обработка команд пользователя.
- 'core' — модели, бизнес-логика, валюты и исключения.
- 'infra' — настройки и инфраструктурные компоненты.
- 'parser_service' — получение, обработка, обновление и хранение курсов.
- 'decorators.py' — декораторы, в том числе логирование операций.
- 'logging_config.py' — настройка логирования.
- 'data/' — файлы с пользовательскими данными и курсами.
- 'logs/' — журналы операций.

## 5. Настройка API-ключа

Для получения фиатных курсов используется ExchangeRate-API.

Необходимо получить API-ключ на сайте:

https://www.exchangerate-api.com/

Ключ хранится в переменной окружения 'EXCHANGERATE_API_KEY'

Windows:
$env:EXCHANGERATE_API_KEY="ВАШ_API_КЛЮЧ"

Linux:
export EXCHANGERATE_API_KEY="ВАШ_API_КЛЮЧ"

После установки переменной запустить приложение в том же окне терминала.

Не следует записывать API-ключ непосредственно в исходный код или публиковать его в репозитории.

Для получения курсов криптовалют используется CoinGecko API.

## 6. Описание команд
После запуска приложения открывается интерактивный интерфейс командной строки с приглашением valutatrade>.

- register --username USERNAME --password PASSWORD - Регистрация нового пользователя.
- login --username USERNAME --password PASSWORD - Вход в учётную запись.
- logout - Выход из текущей учётной записи.
- show-portfolio - Просмотр текущего портфеля в USD.
- show-portfolio --base EUR - Просмотр портфеля с оценкой в указанной базовой валюте.
- buy --currency BTC --amount 0.001 - Покупка указанного количества валюты.
- sell --currency BTC --amount 0.0005 - Продажа указанного количества валюты.
- get-rate --from USD --to EUR - Получение курса одной валюты к другой.
- update-rates - Обновление курсов из всех доступных источников.
- update-rates --source exchangerate - Обновление курсов фиатных валют.
- update-rates --source coingecko - Обновление курсов криптовалют.
- change_password - Изменение пароля текущего пользователя.
- show-rates --currency BTC - Просмотр курса указанной валюты.
- show-rates --top 2 - Просмотр двух валют с наибольшими курсами.
- show-rates --base EUR - Просмотр курсов относительно EUR.
- show-rates - Просмотр сохранённых курсов валют.
- help - Вывод списка доступных команд.
- exit - Завершение работы приложения.

## 8. Parser Service

Parser Service отвечает за получение актуальных курсов из внешних источников.

Используются два источника:

- ExchangeRate-API — курсы фиатных валют.
- CoinGecko — курсы криптовалют.

'RatesUpdater' объединяет результаты обоих источников и передаёт их в 'RatesStorage'.

Если один источник недоступен, система может сохранить данные, полученные из другого источника. Если оба источника недоступны, генерируется 'ApiRequestError'.

## 9. Кэширование и TTL

Для уменьшения количества запросов к внешним API используется кэширование курсов.

Время жизни кэша (TTL) задаётся в 'pyproject.toml':
[tool.valutatrade]
RATES_TTL_SECONDS = 300

TTL равен 300 секундам (5 минутам).

Алгоритм работы:

1. При запросе курса система проверяет время последнего обновления.
2. Если кэш актуален, используются сохранённые значения.
3. Если прошло более 300 секунд, запускается обновление через Parser Service.
4. Новые курсы сохраняются в `rates.json`.
5. История обновлений записывается в `exchange_rates.json`.

## 10. Хранение данных

Данные приложения хранятся в формате JSON:
- users.json - Учётные записи пользователей 
- portfolios.json - Валютные портфели 
- rates.json - Последние актуальные курсы 
- exchange_rates.json - История изменения курсов 

## 11. Логирование

Операции приложения записываются в:
logs/valutatrade.log

Логирование позволяет отслеживать выполнение основных пользовательских операций и диагностировать ошибки.
